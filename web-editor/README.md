# Web editor

A Ruby code editor for web pages running PicoRuby.wasm, with syntax highlighting, line numbers, auto indent, completion and hover.

## Usage

The paths below assume the HTML page is in `web-editor/`.

pico-editor does not load PicoRuby.wasm. Load `@picoruby/wasm-wasi` on your page.

```html
<html>
<head>
  <meta charset="UTF-8">
  <link rel="stylesheet" href="src/editor.css">
  <style>
    #my-editor { height: 400px; }
  </style>
</head>
<body>
  <div id="my-editor"></div>

  <script type="module" src="src/js/prismLoader.js"></script>
  <script type="module" src="../wasm/tiLoader.js"></script>
  <script type="text/ruby" src="src/ruby/support/tokenizer.rb"></script>
  <script type="text/ruby" src="src/ruby/support/text_position.rb"></script>
  <script type="text/ruby" src="src/ruby/features/highlight.rb"></script>
  <script type="text/ruby" src="src/ruby/features/auto_indent.rb"></script>
  <script type="text/ruby" src="src/ruby/features/line_numbers.rb"></script>
  <script type="text/ruby" src="src/ruby/features/completion.rb"></script>
  <script type="text/ruby" src="src/ruby/features/hover.rb"></script>
  <script type="text/ruby" src="src/ruby/editor_event_handler.rb"></script>
  <script type="text/ruby" src="src/ruby/pico_editor.rb"></script>

  <script type="text/ruby">
    editor = PicoEditor.new(JS.document.getElementById('my-editor'))
    editor.value = "puts 1"
  </script>

  <script src="https://cdn.jsdelivr.net/npm/@picoruby/wasm-wasi@latest/dist/init.iife.js"></script>
</body>
</html>
```

The editor fills the element passed to `PicoEditor.new`. Set the height on that element.

See `example/index.html`.

## API

```ruby
editor = PicoEditor.new(root)   # root: JS::Object of an HTML element
editor.value = "puts 1"         # set the text
editor.value                    # => "puts 1"
```

### Appearance

```ruby
editor.theme = 'light'  # 'dark' (default) or 'light'
editor.font_size = 18   # integer pixels, 8–48 (default: 15)
editor.theme           # => "light"
editor.font_size       # => 18
```

Settings apply independently to each editor, including its completion and hover
popups. Font size changes also update highlighting and line numbers. Popups use
a font two pixels smaller than the editor. Invalid settings raise `ArgumentError`.
The example page provides controls for both settings.

Multiple editors can be placed on one page.

```ruby
e1 = PicoEditor.new(JS.document.getElementById('e1'))
e2 = PicoEditor.new(JS.document.getElementById('e2'))
```

## Running the example

From the repository root, complete the [type database prerequisites](../README.md#prerequisites), then build the TI WASM module and serve the repository:

```sh
make wasm
python3 -m http.server 8000
```

`make wasm` requires Docker. With Emscripten, Ruby and the `rbs` gem installed locally, you can use `make -C wasm build` instead.

Open http://localhost:8000/web-editor/example/index.html. Serve the repository root so the page can also load `wasm/tiLoader.js` and `wasm/picoruby_ti.wasm`. The WASM binary is generated by the build and is not committed.

An internet connection is required to load PicoRuby.wasm, Prism.wasm and the WASI shim from jsDelivr.
